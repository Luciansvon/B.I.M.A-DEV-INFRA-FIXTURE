# Fixture release notes

Release publication proof for the reusable `release.yml` workflow from [B.I.M.A-DEV-INFRA](https://github.com/Luciansvon/B.I.M.A-DEV-INFRA).

The `release-fixture.yml` caller uploads one asset and publishes a new tag through the template. The template refuses an existing tag, so this tag is never reused.
